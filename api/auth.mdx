---
title: "Auth API"
description: "Resolve account context and inspect the current authenticated user."
---

Use auth endpoints to resolve login context and confirm what the current token can access.

| Endpoint | Purpose |
|---|---|
| `GET /chefos/api/v1/me` | Return the current user, organization memberships, locations, and permissions |
| `GET /chefos/api/v1/auth/resolve-username` | Resolve a username to its login identity when enabled for the organization |

## Integration notes

- Call `/me` after authentication to confirm the token is valid.
- Cache permission and location data for short periods only.
- Re-check permissions after receiving `401` or `403` responses.
