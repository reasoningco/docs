---
title: "Employee self-service API"
description: "Use employee-facing endpoints for schedules, time off, shift trades, and notifications."
---

Employee self-service endpoints are designed for experiences where the authenticated employee can see or manage their own schedule-related data.

| Endpoint area | Use it for |
|---|---|
| `/chefos/api/v1/scheduling/me` | Resolve the current employee profile |
| `/chefos/api/v1/employee-self-service/upcoming-shifts` | Read upcoming shifts for the current employee |
| `/chefos/api/v1/employee-self-service/time-off` | Create and read time-off requests |
| `/chefos/api/v1/employee-self-service/shift-trades` | Create and read shift trade or drop requests |
| `/chefos/api/v1/employee-self-service/open-shifts` | Read and claim open shifts |
| `/chefos/api/v1/employee-self-service/notifications` | Register devices and manage notification preferences |

## Required context

These endpoints should return data for the current employee by default. Manager-level access requires explicit permissions.
