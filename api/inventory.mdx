---
title: "Inventory API"
description: "Use inventory endpoints for items, counts, recipes, ordering, waste, and vendors."
---

Inventory endpoints support operational workflows around purchasing, counting, recipe costing, and waste tracking.

| Endpoint area | Use it for |
|---|---|
| `/chefos/api/v1/inventory/items` | Read or manage inventory items |
| `/chefos/api/v1/inventory/vendors` | Read or manage vendors and vendor item mappings |
| `/chefos/api/v1/inventory/counts` | Read or manage inventory counts |
| `/chefos/api/v1/inventory/recipes` | Read recipes, ingredients, yields, and costs |
| `/chefos/api/v1/inventory/orders` | Read or manage purchase orders |
| `/chefos/api/v1/inventory/waste` | Read or create waste records |

## Required context

Inventory data is location-scoped. Include the location header for operational reads and writes.
