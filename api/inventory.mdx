---
title: "Inventory API"
description: "Use inventory endpoints for items, counts, recipes, ordering, waste, and vendors."
---

Inventory endpoints support operational workflows around items, vendors, purchasing, invoices, counts, recipes, menus, nutrition, line checks, HACCP, waste, and reporting.

## Core inventory

| Endpoint | Use it for |
|---|---|
| `GET /api/v1/inventory/dashboard` | Read inventory dashboard summary |
| `GET /api/v1/inventory/items` | Search stock items |
| `POST /api/v1/inventory/items` | Create stock items |
| `GET /api/v1/inventory/items/:id` | Read one stock item |
| `PATCH /api/v1/inventory/items/:id` | Update stock item fields |
| `GET /api/v1/inventory/items/:id/details` | Read detail view data |
| `GET /api/v1/inventory/master-items/search` | Search master catalog items |
| `POST /api/v1/inventory/items/import/preview` | Preview an item import |
| `POST /api/v1/inventory/items/import` | Commit an item import |
| `GET /api/v1/inventory/import-history` | List import jobs |
| `GET /api/v1/inventory/categories` | List categories |
| `POST /api/v1/inventory/categories` | Create a category |
| `PATCH /api/v1/inventory/categories/:id` | Update a category |
| `GET /api/v1/inventory/storage-locations` | List storage locations |
| `POST /api/v1/inventory/storage-locations` | Create a storage location |
| `GET /api/v1/inventory/unit-conversions` | List unit conversions |
| `POST /api/v1/inventory/unit-conversions` | Create a unit conversion |
| `GET /api/v1/inventory/uom-settings` | Read unit-of-measure settings |
| `PUT /api/v1/inventory/uom-settings` | Update unit-of-measure settings |
