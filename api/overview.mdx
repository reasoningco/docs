ChefOS APIs are organized by operational domain. Every request is authenticated and evaluated against the token permissions and location scope.

## Base URL

Use the API base URL provided with your credentials. Sandbox and production use separate credentials.

## Required headers

| Header | Value |
|---|---|
| `Authorization` | `Bearer <token>` |
| `X-Location-Id` | Location ID for location-scoped endpoints |
| `Content-Type` | `application/json` for requests with a body |

## Domains

| Domain | Prefix |
|---|---|
| Auth and account context | `/chefos/api/v1/auth`, `/chefos/api/v1/me` |
| Sales | `/chefos/api/v1/sales` |
| Scheduling | `/chefos/api/v1/scheduling` |
| Inventory | `/chefos/api/v1/inventory` |
| Messaging | `/chefos/api/v1/chat` |
| Employee self-service | `/chefos/api/v1/employee-self-service` |
| Assistant | `/chefos/api/v1/sous` |

## Error format

| Field | Description |
|---|---|
| `error` | Human-readable message |
| `code` | Stable machine-readable code when available |
| `details` | Optional structured validation or conflict details |
