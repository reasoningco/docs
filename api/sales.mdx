---
title: "Sales API"
description: "Use sales endpoints for POS imports, metrics, transactions, and forecasts."
---

Sales endpoints support POS imports and reporting workflows.

| Endpoint area | Use it for |
|---|---|
| `/chefos/api/v1/sales/imports` | Upload or track POS sales imports |
| `/chefos/api/v1/sales/transactions` | Read imported checks and line-item activity |
| `/chefos/api/v1/sales/items` | Read menu item performance |
| `/chefos/api/v1/sales/reports` | Read sales summaries by date, location, category, or item |
| `/chefos/api/v1/sales/forecasts` | Read forecast outputs when enabled |

## Required context

Most sales requests are location-scoped. Include `X-Location-Id` unless the endpoint explicitly supports organization-wide reporting.
