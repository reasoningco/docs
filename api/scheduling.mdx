---
title: "Scheduling API"
description: "Use scheduling endpoints for employees, shifts, time off, availability, and labor workflows."
---

Scheduling endpoints support employee roster sync, schedule publishing, time-off workflows, and labor reporting.

| Endpoint area | Use it for |
|---|---|
| `/chefos/api/v1/scheduling/employees` | Read or manage employee roster records |
| `/chefos/api/v1/scheduling/positions` | Read or manage schedulable positions |
| `/chefos/api/v1/scheduling/shifts` | Read, create, or update shifts |
| `/chefos/api/v1/scheduling/time-off` | Read or manage time-off requests |
| `/chefos/api/v1/scheduling/availability` | Read or manage employee availability |
| `/chefos/api/v1/scheduling/reports` | Read labor summaries and schedule metrics |

## Required context

Scheduling data is usually location-scoped. Use employee IDs and shift IDs returned by ChefOS when syncing changes.
