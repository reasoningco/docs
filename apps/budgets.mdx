---
title: "Budgets use cases"
description: "Build workflows around targets, spend controls, alerts, wallet activity, and labor projections."
---

Use the Budgets app and API when an integration needs to connect spend planning to sales performance.

| Workflow | APIs to start with |
|---|---|
| Import monthly or weekly sales targets | `POST /api/v1/sales/budgets/targets/import/preview`, `POST /api/v1/sales/budgets/targets/bulk` |
| Show budget status in another dashboard | `GET /api/v1/sales/budgets`, `GET /api/v1/sales/budgets/wallet`, `GET /api/v1/sales/budgets/alerts` |
| Sync spend categories | `GET /api/v1/sales/budgets/categories`, `POST /api/v1/sales/budgets/categories` |
| Track purchases against budgets | `GET /api/v1/sales/budgets/:id/transactions`, `POST /api/v1/sales/budgets/:id/transactions` |
| Compare labor plans to sales targets | `GET /api/v1/sales/budgets/labor-projection` |

## Data model

Budgets connect targets, actual sales, categories, transactions, pending POS activity, and location scope. Keep external category mappings stable so imported spend can be reconciled.
