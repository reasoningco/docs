---
title: "Employee self-service integrations"
description: "Build employee-facing workflows for schedules, time off, shift trades, and notifications."
---

Employee self-service APIs support mobile, kiosk, and partner experiences where employees manage their own schedule-related tasks.

## Common workflows

| Workflow | What to sync |
|---|---|
| Upcoming shifts | Published shifts for the authenticated employee |
| Time-off requests | Create requests, read request status, and show approval history |
| Shift trades | Create trade/drop requests and read approval status |
| Open shifts | List claimable shifts and submit claims |
| Push notifications | Register devices and update notification preferences |

## Recommended approach

Employee self-service access should only expose data for the current employee unless the token has explicit manager-level permissions.
