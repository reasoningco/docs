title: "Inventory integrations"
description: "Build workflows for items, recipes, counts, ordering, waste, and vendors."
---

Inventory integrations help restaurants keep item data, purchasing, counts, recipes, and waste workflows in sync.

## Common workflows

| Workflow | What to sync |
|---|---|
| Item catalog | Item names, units, categories, vendor mappings, pack sizes |
| Counts | Count sessions, counted quantities, variance, and status |
| Recipes | Ingredients, yields, prep instructions, and cost inputs |
| Ordering | Purchase orders, vendor details, submitted quantities, receiving status |
| Waste | Waste entries, reasons, quantities, costs, and location |

## Recommended approach

Start by reading item and vendor data. Once identifiers are mapped, add write access for the exact workflow you are automating.
