Use ChefOS APIs to connect external systems without duplicating restaurant data by hand.

| Use case | API domains to start with |
|---|---|
| Pull performance metrics into a BI tool | Sales, Scheduling, Inventory |
| Import POS sales each day | Sales |
| Sync employee schedules to another system | Scheduling, Employee self-service |
| Connect inventory or vendor workflows | Inventory |
| Build an employee mobile experience | Employee self-service, Messaging, Scheduling |
| Trigger operational summaries | Sous AI, Sales, Scheduling, Inventory |

## Good integration behavior

- Sync by ChefOS IDs, not display names.
- Keep a record of the last successful sync time.
- Make writes idempotent when possible.
- Show clear operator-facing errors when a token lacks access.
- Avoid broad tokens for narrow workflows.
