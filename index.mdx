## Quick start

1. Request API credentials for the organization you are integrating with.
2. Pick the target environment and base URL.
3. Send `Authorization: Bearer <token>` on every API request.
4. Include the active location header when reading or writing location-scoped data.
5. Start with a read-only endpoint, then request write scopes when the workflow is ready.

## Core domains

| Domain | Build with it when you need to |
|---|---|
| Sales | Import POS data, read revenue metrics, compare performance, or power reporting |
| Scheduling | Sync shifts, employees, availability, time-off, and labor forecasts |
| Inventory | Manage items, counts, recipes, ordering, waste, and vendor workflows |
| Messaging | Connect operational conversations and employee notifications |
| Employee self-service | Build mobile or kiosk experiences for schedules, trades, and time off |
| Sous AI | Trigger permission-aware assistant actions from approved workflows |
