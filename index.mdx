## Quick start

1. Ask an organization admin to create a scoped API token in ChefOS Developer Access.
2. Pick the sandbox or production base URL.
3. Send `Authorization: Bearer <token>` on every protected request.
4. Call `/api/v1/locations/mine` to confirm location access.
5. Include `X-Location-Id` when reading or writing location-scoped data.
6. Start with read-only scopes, then request write scopes when the workflow is ready.

## Core domains

| Domain | Build with it when you need to |
|---|---|
| Sales | Import POS data, read revenue metrics, compare performance, or power reporting |
| Budgets | Track sales targets, wallet usage, budget categories, alerts, and labor projections |
| Scheduling | Sync shifts, employees, availability, time-off, and labor forecasts |
| Inventory | Manage items, counts, recipes, ordering, invoices, waste, and vendor workflows |
| POS | Register checkout, catalog reads, shift/day closeout, refunds, and payments |
| Integrations | Connect providers such as Toast, Square, Clover, OpenTable, When2Work, and QuickBooks |
| Messaging | Connect operational conversations and employee notifications |
| Employee self-service | Build mobile or kiosk experiences for schedules, trades, and time off |
