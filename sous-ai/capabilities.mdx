title: "Assistant capabilities"
description: "Review Sous AI actions available to approved integrations."
---

Sous AI capabilities are permission-aware. A workflow can only access data and actions available to the authenticated user or token.

| Action type | What it can do |
|---|---|
| `navigate` | Open a permitted ChefOS destination |
| `report` | Summarize approved operational data |
| `toggle_notification` | Change one notification preference |
| `toggle_notification_category` | Change a notification category preference |
| `schedule_report` | Create a recurring summary when allowed |

## Best practices

- Prefer explicit actions over ambiguous prompts.
- Include location context when the request is location-specific.
- Show users when a request is blocked by permissions.
- Keep scheduled reports narrow enough to be useful.
