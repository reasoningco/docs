---
title: "Sous AI assistant"
description: "Use permission-aware assistant capabilities for navigation, summaries, notifications, and scheduled reports."
---

Sous AI is the ChefOS assistant layer. Approved integrations can trigger assistant workflows that respect the same permissions and location scopes as the rest of the platform.

## Capabilities

| Capability | Example |
|---|---|
| Navigation | Open a permitted ChefOS screen for a user |
| Reports | Generate a summary from sales, labor, or inventory data |
| Notification control | Mute or re-enable a user's notification category |
| Scheduled summaries | Deliver recurring summaries to an approved channel |

## Integration guidance

Use assistant workflows for operator-facing actions. Do not use them as a replacement for deterministic API reads and writes.
