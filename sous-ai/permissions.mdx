title: "Assistant permissions"
description: "Understand how Sous AI applies API permissions and location scoping."
---

Sous AI uses the same permission model as the rest of ChefOS.

## Permission behavior

| Behavior | Result |
|---|---|
| User lacks a route permission | Navigation is not offered or is blocked |
| User lacks report data access | The report request is rejected |
| Location is outside scope | The action cannot read or write that location |
| Notification preference is personal | The user can update their own preference |

Design assistant integrations so blocked requests explain what permission is missing and how the operator can resolve it.
